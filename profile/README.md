## 👋 About

**Kobesoft Labs** は、神戸ソフト株式会社のエンジニアが運営するオープンな開発スペースです。
日々の開発の中で生まれたツール・ライブラリ・技術検証を、ここで共有していきます。

## 🧪 What we do

| | |
|---|---|
| 🛠 **Tools** | 業務や開発を楽にする小さなツール・CLI |
| 📦 **Libraries** | 社内で育てた再利用可能なコンポーネント |
| 🔬 **Experiments** | 新しい技術の検証・プロトタイプ |
| 📝 **Templates** | プロジェクトの雛形・設定のベストプラクティス |
