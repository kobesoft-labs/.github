## 👋 About

**Kobesoft Labs** は、神戸ソフト株式会社のエンジニアが運営するオープンな開発スペースです。
日々の開発の中で生まれたツール・ライブラリ・技術検証を、ここで共有していきます。

## 🧪 What we do

| | |
|---|---|
| 🛠 **Tools** | 業務や開発を楽にする小さなツール・CLI |
| 📦 **Libraries** | 社内で育てた再利用可能なコンポーネント |
| 🔬 **Experiments** | 新しい技術の検証・プロトタイプ |
| 📝 **Templates** | プロジェクトの雛形・設定のベストプラクティス |

## 📂 Repositories

### 🗾 Open Data

日本の公的なオープンデータを、そのまま使える SQLite / JSON にして毎月自動で配布しています。

| Repository | 内容 | 更新 |
|---|---|---|
| [houjin-bangou-db](https://github.com/kobesoft-labs/houjin-bangou-db) | 国税庁 法人番号公表サイトの法人番号データ | 毎月 |
| [jp-postal-code-db](https://github.com/kobesoft-labs/jp-postal-code-db) | 日本郵便の郵便番号データ（KEN_ALL・事業所） | 毎月 |
| [jp-phone-number-db](https://github.com/kobesoft-labs/jp-phone-number-db) | 総務省「電気通信番号指定状況」から作った電話番号の決まり | 毎月 |

最新版は各リポジトリの Releases（`releases/latest/download/...`）から取得できます。
